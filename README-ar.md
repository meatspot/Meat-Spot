# MEAT SPOT — النسخة المحلية
المشروع Next.js موجود في هذا المجلد. النسخة الحالية تحتوي واجهة هولندية وعربية وإنجليزية وتركية، سلة وطلبات استلام من المحل، دخول Google، ولوحة إدارة للمنتجات والأسعار والصور والأقسام والمواعيد والمحتوى ومعلومات المكان.

## التشغيل
Node.js 22 أو أحدث، ثم:
```powershell
npm ci
npm run dev
```
افتح http://localhost:3000/nl. دون مفاتيح Supabase يعرض الموقع صفحات المحل والصور، وتبقى المنتجات والطلبات والدخول غير متاحة. هذه الحالة ليست متجراً منشوراً.

## الحالة الحالية
الشعار المعتمد مستخدم كما ورد. الاسم Fuozi Abu Alfoz. الصور الأصلية محفوظة، وأصول الموقع في public/images. الطاولة تتفاعل مع اختيار الأنواع، وتوجد حركة للمقص والساطور مع احترام إعداد تقليل الحركة.
الأسعار ومحتوى الخصوصية والشروط ومدة تجهيز الطلب وسعة الاستلام تحتاج بيانات حقيقية من صاحب المحل. لا توجد أسعار تجريبية منشورة.
الرمز البريدي المقدم 9641 MK؛ سجل PDOK للعنوان Veenlustplein 11 يعرض 9641 MG. يجب حسم الفرق قبل نشر عنوان المحل أو إعداد إحداثياته.
